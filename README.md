# Java Enum Study

## 📌 Sobre o projeto

Este projeto foi desenvolvido como parte dos estudos da linguagem Java, com foco na utilização de **enumerações (Enum)** em aplicações orientadas a objetos.

O sistema simula um gerenciamento simples de pedidos, demonstrando como utilizar enums para representar estados de um pedido, além de aplicar conceitos fundamentais de Programação Orientada a Objetos (POO).

> **Observação:** Este projeto possui finalidade exclusivamente acadêmica e foi desenvolvido como exercício de estudo para aprimoramento dos conhecimentos em Java.

---

## 🎯 Objetivos

* Compreender o funcionamento de enumerações (`Enum`);
* Utilizar enums como atributo de uma classe;
* Converter Strings para enums utilizando `valueOf()`;
* Aplicar conceitos básicos de Programação Orientada a Objetos;
* Organizar um projeto Java em pacotes.

---

## 🛠️ Tecnologias utilizadas

* Java
* Programação Orientada a Objetos (POO)

---

## 📚 Conceitos abordados

* Enum (`enum`)
* Classes e Objetos
* Encapsulamento
* Construtores
* Getters e Setters
* Sobrescrita do método `toString()`
* Organização em pacotes
* Conversão de String para Enum (`valueOf()`)
